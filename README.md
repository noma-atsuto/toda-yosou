# 戸田ボートレース予想アプリ（iPhone用）

毎日自動で「データ取得 → 予想 → 結果と照合 → 学習し直し」をくり返し、
だんだん予想を育てていく iPhone 向けのアプリです。

- **予想タブ**：その日の全レースの1着率・2着内率・3着内率、3連単〜単勝の買い目と目安オッズ、今日の注目レース
- **成績タブ**：締切前の予想と実際の結果を照合した、本番の的中率と回収率の推移
- **学習タブ**：毎日の学習でどれだけ当たるようになったか、着順に効いている項目

> 確率は過去データからの推定で、的中や利益を保証するものではありません。

---

## しくみ（ざっくり）

| いつ（日本時間） | 何をするか |
|---|---|
| 毎朝 8:30 | 前日までの結果を取り込み、学習し直す（4通りの設定を試して、いちばん当たるものを採用） |
| 9:00〜17:40（20分おき） | 展示（直前の試運転）の情報で予想を更新。締切を過ぎたレースは予想を固定 |
| 19:00・22:00 | 最終レースまでの結果と照合し、翌日の出走表が出ていれば先に予想 |

すべて GitHub（プログラムを保存・自動実行できるサービス）の上で動くので、Mac の電源が切れていても動きます。
※GitHub の自動実行は混雑すると数分〜数十分遅れることがあります。

## はじめの準備（1回だけ・約20分）

### おすすめ：Claude Code に任せる
1. このフォルダ（toda-app）を Mac の好きな場所に置きます。
2. ターミナルでこのフォルダを開いて `claude` と入力し、Claude Code を起動します。
3. 下の文章をそのまま貼り付けます。

```
このフォルダを GitHub の新しい公開リポジトリ「toda-yosou」として push してください。
そのあと次の設定をしてください。
1. Settings → Actions → General → Workflow permissions を「Read and write permissions」にする
2. Settings → Pages で「Deploy from a branch」「main」「/docs」を選んで公開する
3. Actions の「自動予想」を mode=setup で手動実行する（過去1年分を集めて学習。15〜30分かかる）
終わったら、iPhone で開く URL を教えてください。
gh コマンドが入っていなければ、入れ方とログインのしかたを案内してください。
```

### 自分で設定する場合
1. GitHub で新しいリポジトリ「toda-yosou」を**公開（Public）**で作ります。
2. このフォルダの中身をすべてアップロードします
   （`.github` フォルダは Finder で見えないことがあります。見えないときは `command + shift + .` で表示）。
3. **Settings → Actions → General** の一番下「Workflow permissions」を **Read and write permissions** にして保存。
4. **Settings → Pages** で Source を **Deploy from a branch**、Branch を **main** と **/docs** にして保存。
5. **Actions** タブ → 左の「自動予想」→ 右の **Run workflow** → mode を **setup** にして実行。
   緑のチェックがつけば完了です（15〜30分）。

### iPhone に入れる
1. iPhone の **Safari** で `https://（GitHubのユーザー名）.github.io/toda-yosou/` を開きます。
2. 下の共有ボタン（□に↑）→ **ホーム画面に追加** を押します。
3. ホーム画面の「戸田予想」アイコンから、アプリのように使えます。

## よくある質問

**Q. お金はかかりますか？**
公開リポジトリなら GitHub の自動実行も公開ページも無料です（2026年9月時点の情報のため、最新は GitHub の料金ページで要確認）。
非公開（Private）にすると、公開ページ（Pages）を使うのに有料プランが必要になります。

**Q. 公開リポジトリだと、ほかの人にも見えますか？**
はい。予想ページの URL を知っている人は見られます。個人情報は含まれていません。

**Q. しばらく放っておくと止まりますか？**
公開リポジトリでは、60日間まったく動きがないと自動実行が止まる決まりがあります。
このアプリは毎日自動で更新を記録するので止まりにくいはずですが、念のため
Actions タブで「自動予想」が動いているかをたまに確認してください（要確認）。

**Q. 予想を良くしたいときは？**
Claude Code で、たとえば次のようにお願いします（CLAUDE.md にしくみを書いてあるので、Claude Code が読んで作業します）。

```
成績タブの数字を見て、どの買い方がいちばん回収率が良いか分析して
```
```
予想の特徴量に「選手の直近3節の成績」を追加して、tests/run_sim.sh で確認してから反映して
```
```
オッズを取り込んで、目安オッズより実際のオッズが高い「割安な買い目」に印をつけて
```
```
平和島（04）も予想できるようにして
```

## フォルダの中身

| 場所 | 中身 |
|---|---|
| `engine/` | 予想エンジン（Python。追加インストール不要） |
| `docs/` | iPhone で見る画面。`docs/data/` はエンジンが自動で作るデータ |
| `store/` | 取得した戸田のデータ（日ごと） |
| `predictions/` | 毎日の予想の記録（締切時点で固定） |
| `model/` | 学習済みの予想モデルと学習の履歴 |
| `.github/workflows/auto.yml` | 自動実行の時間割 |
| `tests/` | 模擬データでの動作確認（`bash tests/run_sim.sh`） |
| `CLAUDE.md` | Claude Code 向けの説明書 |

データ：Boatrace Open API（有志による非公式の無料データ）https://github.com/BoatraceOpenAPI
